# Zwei-Faktor-Authentifizierung und Passkeys

Zusätzliche Sicherheitsstufen erschweren den Zugriff auf Dein Konto, auch wenn Dein Passwort bekannt wird.

## Worum geht es?

Bei der Zwei-Faktor-Authentifizierung brauchst Du zusätzlich zum Passwort einen bestätigten Faktor. Passkeys verwenden ein neues, auf Deinem Gerät gespeichertes Anmeldeverfahren.

---

### 👍 Mein Tipp

Nutze für wichtige Konten eine Authentifizierungs-App oder einen Sicherheitsschlüssel, wenn eine sichere Option angeboten wird.

---

### ⚠️ Häufiger Fehler

SMS-Codes können nützlich sein, sind aber anfälliger als eine Authentifizierungs-App oder ein Passkey.

---

### 📌 Merke Dir

Eine zweite Sicherheitsstufe schützt Dich, wenn ein Passwort versehentlich bekannt wird.

---

## Schritt für Schritt

1. Öffne die Sicherheitseinstellungen des Kontos.
2. Wähle eine angebotene zusätzliche Sicherheitsstufe.
3. Folge den Anweisungen auf dem Bildschirm.
4. Bewahre Wiederherstellungscodes geschützt auf.
5. Prüfe danach eine sichere Anmeldung.

---

### ✅ Checkliste

- [ ] Meine wichtigste Anmeldung ist zusätzlich geschützt.
- [ ] Meine Wiederherstellungscodes sind gesichert.
- [ ] Ich habe den Anmeldevorgang einmal geprüft.
