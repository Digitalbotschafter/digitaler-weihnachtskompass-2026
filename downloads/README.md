# Downloads

In diesem Bereich können später PDF-Dateien, Vorlagen und druckbare Checklisten bereitgestellt werden.

## Worum geht es?

Downloads machen ausgewählte Inhalte offline nutzbar. Die Dateien sollten regelmäßig auf Aktualität und Lesbarkeit geprüft werden.

---

### 👍 Mein Tipp

Bewahre heruntergeladene Vorlagen in einem eigenen Ordner auf und ergänze das Jahr im Dateinamen.

---

### ⚠️ Häufiger Fehler

Eine Datei stammt aus einer unbekannten Quelle oder wurde versehentlich mehrfach gespeichert.

---

### 📌 Merke Dir

Lade nur Dateien aus vertrauenswürdigen Bereichen herunter und öffne sie mit einer aktuellen Anwendung.
