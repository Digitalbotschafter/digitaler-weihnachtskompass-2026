# Cloud-Dienste verstehen

Cloud-Dienste speichern Daten auf Servern, auf die Du über das Internet zugreifen kannst.

## Worum geht es?

Unter Cloud versteht man Speicher oder Programme, die nicht nur auf Deinem Gerät liegen, sondern von einem Anbieter bereitgestellt werden.

---

### 👍 Mein Tipp

Prüfe vor der Nutzung, ob Fotos oder Dokumente automatisch hochgeladen werden. Speicherkosten und Datenschutz hängen davon ab.

---

### ⚠️ Häufiger Fehler

Viele glauben, dass Daten in der Cloud verschwinden könnten, wenn sie auf dem Gerät gelöscht werden. Je nach Einrichtung werden Löschungen synchronisiert.

---

### 📌 Merke Dir

Die Cloud ist praktisch, aber Deine Anmeldung und Deine Freigaben bestimmen den Zugriff.

---

## Schritt für Schritt

1. Prüfe, welchen Cloud-Dienst Du bereits nutzt.
2. Lies, welche Daten synchronisiert werden.
3. Kontrolliere Speicherplatz und Kosten.
4. Prüfe Freigaben für Ordner und Dateien.
5. Aktiviere bei wichtigen Konten eine zusätzliche Sicherheitsstufe.

---

### ✅ Checkliste

- [ ] Ich kenne meinen Cloud-Anbieter.
- [ ] Ich weiß, welche Daten synchronisiert werden.
- [ ] Meine Freigaben sind geprüft.
